# Ruby Dungeon Crawler

A lightweight, terminal-based adventure game built in Pure Ruby.

## Features
- Procedural-style 2D grid rendering.
- Real-time movement logic using WASD keys.
- Collision detection (players cannot walk through walls).

## How to Play
1. Ensure you have Ruby installed (`ruby -v`).
2. Clone this repo: `git clone [YOUR_REPO_URL]`
3. Run the game: `ruby game.rb`

🎮 How to Control the Game
Once the game starts, you will see the grid in your terminal:

Look for the @: That is you (the player).

Look for the E: That is the exit you need to reach.

To Move:

Type w and press Enter to move Up.

Type s and press Enter to move Down.

Type a and press Enter to move Left.

Type d and press Enter to move Right.

To Quit: Type q and press Enter.
